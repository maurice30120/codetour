# AI-Generated Code Tours

This context defines the guided explanations generated by an AI agent to help developers understand a codebase or a set of changes.

## Language

**Tour**:
An ordered sequence of contextual explanations attached to relevant locations in a codebase. Its subject and output filename are chosen by the Tour Generator rather than by a server-defined tour category.
_Avoid_: Walkthrough file, generated documentation

**Tour Anchor**:
A stable location in the codebase that associates a Tour step with the code or directory it explains.
_Avoid_: Pointer, target

**Tour Generator**:
An AI agent that chooses a Tour's subject and filename, analyzes the relevant workspace state (Git or otherwise), and proposes the Tour through CodeTour's single MCP tool `create_tour`. The server only validates and persists the proposal; it performs no Git access and never writes a CodeTour `ref`.
_Avoid_: MCP client, tour writer, Project Tour generator, Changes Tour generator
