# Distribute and discover the MCP server with the extension

The VS Code extension bundles the compiled stdio MCP server and registers one server definition per workspace folder so GitHub Copilot discovers it without project configuration. The server derives its single workspace from the process working directory instead of a CodeTour-specific `--workspace-root` argument; this also lets a global Codex registration work in every task because Codex starts it in the task directory. CodeTour exposes explicit configure and repair commands for Codex, whose global registry cannot discover servers contributed by a VS Code extension. This supersedes the launch mechanism in ADR-0005 while preserving its confinement and transport decisions.

The MCP server definition API requires VS Code 1.101, so the extension's minimum VS Code version moves to 1.101. In that API version, `CommentThread.range` is optional. Existing player and recorder code therefore checks that a source range exists before navigating to or recording a file step: player focus becomes a no-op without a navigable range, while recording reports an explicit error. These are compatibility adjustments caused by the required API upgrade, not changes to MCP behavior.
