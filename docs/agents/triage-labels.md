# Libellés de triage

Les compétences utilisent cinq rôles de triage canoniques. Ce fichier associe ces rôles aux libellés réellement employés dans le suivi des tickets de ce dépôt.

| Libellé dans mattpocock/skills | Libellé dans notre suivi | Signification |
| ------------------------------ | ------------------------- | ------------- |
| `needs-triage` | `needs-triage` | Un mainteneur doit évaluer ce ticket |
| `needs-info` | `needs-info` | En attente d’informations supplémentaires de la personne ayant signalé le problème |
| `ready-for-agent` | `ready-for-agent` | Entièrement spécifié et prêt à être traité par un agent autonome |
| `ready-for-human` | `ready-for-human` | Nécessite une implémentation humaine |
| `wontfix` | `wontfix` | Ne sera pas traité |

Lorsqu’une compétence mentionne un rôle, par exemple « appliquer le libellé prêt pour un agent autonome », utiliser le libellé correspondant dans ce tableau.

Modifier la colonne centrale si le vocabulaire du suivi des tickets évolue.
