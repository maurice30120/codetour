Call the Skill tool twice, for "grilling" and "domain-modeling".

When relationships, flows, states, sequences, or the emerging design tree are easier to understand visually, propose a Mermaid diagram. Generate it only from decisions already settled with the user, place it in the most relevant Markdown document, and update it as later answers change the design. Choose the Mermaid diagram type that best expresses the information; keep labels in the project's canonical domain language.

Before finishing, verify every Mermaid block is syntactically valid and consistent with the glossary and ADRs.
