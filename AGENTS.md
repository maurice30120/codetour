## Repositories

- The workspace root is the CodeTour Git repository; its application lives in `codetour/`. Follow `codetour/AGENTS.md` when working there.
- `TokenEconomizer/` is a Git submodule and a separate repository. Follow its `AGENTS.md` when working there. The parent records only the submodule commit, not its uncommitted files.
- `wt-*/` directories are local worktrees, ignored by the parent repository. Check which repository and branch each worktree belongs to before using it.

## Working across repositories

1. Before changing Git state, check `git status --short --branch` at the root and in `TokenEconomizer/`. Preserve existing changes, including untracked files and staged changes, and verify the current branches rather than assuming their names.
2. Make and test changes in the relevant project; builds, tests and `npm run` scripts run from `codetour/`.
3. A Tour generated by an agent is created from the workspace root — the creation journal and `.tours/` depend on it.
4. When commits are requested for both projects, commit TokenEconomizer first, then stage its updated submodule pointer in the parent along with the intended CodeTour changes. A parent commit alone never commits TokenEconomizer's files.
5. When publishing both projects is requested, push the TokenEconomizer commit to its authorized remote before publishing the parent commit that references it. Follow TokenEconomizer's publishing instructions.

The root migration moves CodeTour's tracked files under `codetour/`; older branches may still use the former layout. Inspect the working tree and preserve local changes before switching branches or creating worktrees.
