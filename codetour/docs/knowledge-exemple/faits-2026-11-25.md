## Reading a fact

| Field | Meaning |
| --- | --- |
| `claim` | what the fact asserts, in one sentence |
| `injection` | the words the agent receives, usually the claim phrased for the manual |
| `fire` | sessions that exercised the fact over sessions observed; a fact is injected once the
  ratio clears the gate and the block budget still has room |
| `detector` | the command or file pattern that recognises the situation, and what fires it |
| `state` | `CANDIDATE` (learning), `ACTIVE` (injected when the gate clears), `RETIRED` (kept, never injected) |

A fact is re-read from the sessions, so this file is a snapshot, not a contract: the plugin's
state under `~/.tokeneconomizer` is the source of truth, and `te microskills` lists what the next
session would receive.
