# Glossary Map

## Contexts

- [Memory, Knowledge and generation runs](./CONTEXT.md): what a workspace remembers, and the run that produces and consolidates it — Memory Entries, the Knowledge Catalogue, Knowledge Consolidation Operations, the Run State and the AgentStop Guard.
- [Reader, narration and agent selection](./GLOSSARY.md): how a Tour is presented and who answers it — Tour and Project Images, the narration spell dictionary, Agent Profiles and Effective Models.

## Relationships

- **CONTEXT.md → GLOSSARY.md**: a Generation Run resolves and reports the Agent Profile that answered it, in the Pre-Launch Report and the Run Usage Metrics. The reader vocabulary names the agents; the memory vocabulary names the run artefacts.
- **No term is defined in both files.** A term belongs to exactly one context: the one whose work employs it. When a term is needed on both sides, the second context refers to it through its own vocabulary rather than restating it.
